Administrators can allow participants to download video and audio files directly from the player's control bar. Downloads are disabled by default and configured separately for each media item, including media attached to skills, quiz questions, and survey questions.

To enable downloads:

1. Open the skill's **Audio/Video** page, or click **Add Audio/Video** next to a quiz or survey question.
2. Upload a file or configure an external media URL.
3. Turn on **Allow Downloads**.
4. Click **Save and Preview** to save the setting and verify that the download button appears in the player.

The setting applies to both video and audio, whether uploaded to SkillTree or hosted externally. For externally hosted media, the browser and external server determine whether the file is saved directly or opened in a new tab.

To remove the download button, turn off **Allow Downloads** and save the settings. Selecting a new upload or switching between upload and external-link modes resets this setting to disabled; enable it again if you want the replacement media to be downloadable.

Downloading a file does not count as watching or listening to it and does not award playback-based skill credit.
